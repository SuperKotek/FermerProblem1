# Fermer-Problem
#### ЗадачаФермера - это Windows Forms приложение для вычисления площадей различных геометрических фигур по заданному периметру. Программа включает:

- Расчет площадей для 6 типов фигур
- Поддержку пользовательских n-угольников
- Проверку корректности введенных данных
- Округление результатов до 5 знаков после запятой

### Функционал:
Поддерживаемые фигуры:
- Треугольник (равносторонний) | Формула: S = (P²√3)/36
- Квадрат | Формула: S = P²/16
- Круг | Формула: S = P²/(4π)
- Ромб (с углами 60° и 120°) | Формула: S = (P²√3)/32
- Пятиугольник (правильный) | Формула: S = (P²√3)/24
- n-угольник (правильный) | Формула: S = P²/(4n·tan(π/n))

Особенности реализации
	Библиотека Farmer содержит все математические расчеты
	Каждая фигура имеет свою форму для ввода данных
	Главная форма (MainForm) обеспечивает навигацию между формами
	Полная проверка входных данных:
	Отрицательные значения
	Некорректные форматы
	Пустые значения


### Использование:

Запустите приложение
Выберите тип фигуры из главного меню
Введите значение периметра
Для n-угольника укажите количество сторон
Нажмите кнопку "Рассчитать"
Результат отобразится в соответствующем поле


### Технические детали
Архитектура проекта:

Библиотека расчетов:
	Статический класс Farmer с методами для каждой фигуры
	Все методы принимают периметр и возвращают площадь

Пользовательский интерфейс:
	Главная форма (MainForm) - навигационное меню
	6 специализированных форм для каждой фигуры
	Единообразный интерфейс всех форм

Обработка ошибок:
	Проверка на отрицательные значения
	Проверка формата ввода
	Обработка исключений
